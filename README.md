# Data Analytics Projects

兩份資料科學相關課程期末專案，涵蓋時間序列預測與客戶行為分類，結合傳統機器學習與深度學習方法。

---

## 蔬菜菜價預測與食譜推薦

**目標**：預測桃園區批發蔬菜價格趨勢，找出近期較便宜的蔬菜品項，並結合 Generative AI 自動生成食譜，協助消費者做出更聰明的採買決策。

### 動機

- 消費者在菜市場缺乏即時、集中的價格資訊，比價耗時費力
- 購入食材後缺乏食譜指引，導致時間及食材浪費

### 資料來源

[農產品批發市場交易行情站](https://amis.afa.gov.tw/m_veg/VegProdDayTransInfo.aspx)

## Project 2 — 客戶流失預測與行為分類

**目標**：利用 2020–2022 年銷售與通話紀錄，建構每位客戶的動態行為特徵，預測其 2022 年的客戶狀態（Loyal / Partial Churn / Churn）。

### 特徵設計：動態 RFM 延伸

每位客戶以 **24 個月** 為序列長度，每個月計算 7 維特徵：

| 特徵 | 說明 |
|------|------|
| R | 距上次購買天數 |
| F | 當月購買次數 |
| M | 當月消費金額 |
| C | 當月通話次數 |
| 個人平均回購週期 | 依歷史購買間隔動態計算 |
| 週期偏差 | 距預期回購日的提前或超期天數 |
| 逾期倍率 | 超過回購週期的倍數（> 1 代表流失風險上升） |

### 模型比較

- **深度學習**：LSTM、CNN（時序特徵提取）
- **傳統機器學習**：XGBoost、Random Forest 等
- 處理類別不平衡：`class_weight='balanced'`
- 評估指標：**Macro F1-score**、Confusion Matrix
